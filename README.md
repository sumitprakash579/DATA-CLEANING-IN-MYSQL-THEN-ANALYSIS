# DATA-CLEANING-IN-MYSQL-THEN-ANALYSIS
End-to-end Q1 2024 retail sales analysis: data cleaned in MySQL (joins, CTEs), analysed in Excel (Power Query, Power Pivot, data modeling, pivot tables), and presented in PowerPoint.

Sales Analysis: Q1 2024

An end-to-end analysis of retail sales for January to March 2024, from raw data to a final presentation.

Workflow

Data cleaning (MySQL): Cleaned and prepared the data using joins and CTEs.
Analysis (Excel): Used Power Query for transformation, Power Pivot and data modeling for relationships and measures, and charts to visualize trends.
Reporting (PowerPoint): Documented the findings in a final presentation.

What's covered

Month-wise performance (Turnover, ABV, ABQ, ASP)
Product and category performance
Store-wise performance
Customer analysis by segment (Silver, Gold, Platinum)
Key observations and insights

Key insight: Turnover fell every month, from ₹14.81L in January to ₹10.49L in March (about 29% down), while items per bill stayed flat. The drop came from fewer sales, not smaller baskets.

Tools: MySQL, Excel (Power Query, Power Pivot), PowerPoint
